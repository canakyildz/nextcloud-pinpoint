# Evals

`dataset/` holds 30 synthetic documents with ground truth, generated by `generate.py` from a fixed seed:
16 invoices and 8 receipts in English (US and UK), German and French, and 6 of them again as scanned images.
They vary the things that break extraction: number formats (`1,234.56`, `1.234,56`, `1 234,56`), date
formats (`03/14/2026`, `14/03/2026`, `14.03.2026`, `14 mars 2026`), dates that are ambiguous on purpose,
missing optional fields, and scans with skew, blur and noise. All companies and people are made up.

The generator checks its own output: every ground-truth quote must be found verbatim in the PDF's text, or
it refuses to write the document.

## `run.py oracle`

The model is replaced by the ground truth with one fault injected at a time:

| Fault | What the "model" does | Expected |
|---|---|---|
| `correct`, `wrong_page` | the right answer (the page number off by one) | verified |
| `hallucinated` | a value and a quote that aren't in the document | not verified |
| `contradicts_quote` | the real quote with a clearly different value | not verified |
| `near_miss` | the real quote, value one character, one cent or one day off | not verified |
| `quote_not_in_document` | the right value with a quote that isn't there | not verified |
| `missing_quote` | the right value without a quote | not verified |
| `invented_field` | a value for a field the document doesn't have | not verified |
| `swapped_amounts` | total and tax swapped, each with its real quote | not verified (the sum check) |

All other fields of every faulty run are checked too, as positive controls. A correct value is expected to
be verified, except where it's correct to send it to review: an option the model inferred ("Card" from
"Kartenzahlung"), a date that's ambiguous in that document, a value on a scan that OCR didn't read literally,
or an amount in a sum that doesn't add up. CI fails if either rate drops below 97%.

```bash
python evals/run.py oracle --check --report evals/results/oracle.md
```

## `run.py openai`

The whole pipeline with a real model behind any OpenAI-compatible endpoint:

```bash
python evals/run.py openai --base-url http://localhost:11434/v1 --model qwen2.5:7b --report evals/results/qwen2.5-7b.md
```

The number to watch is **wrong values marked verified**. A wrong value that goes to review costs a person a
few seconds. A wrong value marked verified goes into the table unnoticed.
